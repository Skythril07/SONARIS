# SONARIS — Fresh Minimal Professional UI

A fresh, user-friendly responsive demo frontend for SONARIS (SIH26057).

## UI direction
- Sidebar-based workspace navigation
- Professional marine operations theme with calm teal accents
- Light theme by default, with dark-mode toggle
- Clear summary cards and processing pipeline
- Sonar + geospatial views with linked detection selection
- Detection register with filtering
- Evidence review panel with confirm/reject actions
- CSV, GeoJSON and GPX export
- Responsive layouts for desktop, tablet and mobile

## Run
```bash
npm install
npm run dev
```
